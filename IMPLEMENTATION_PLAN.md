# Implementation Plan — Qalbanion

Following the 13-phase roadmap defined in the Product & Development Specification.

---

## Progress Overview

- [x] **Phase 0: Project Inspection and Architecture**
  - Confirmed technology stack (React 19, TypeScript, Vite, Tailwind CSS v4, Lucide).
  - Designed folder structure and entity models.
  - Initialized Git, linked GitHub remote repository, configured `.gitignore`.
- [x] **Phase 1: Design System and Application Shell**
  - Configured "Quiet Editorial" theme tokens (warm ivory `#FBF9F5`, soft cream `#F5F2EB`, charcoal `#2C2B29`, muted olive `#5E6D55`).
  - Added Newsreader (editorial serif) and Inter (clean UI sans) typography.
  - Built persistent desktop Sidebar, mobile drawer, and ThemeProvider with dark mode.
  - Implemented client-side routing for Home, Journal, Editor, Collections, Reflections, Insights, and Settings.
- [x] **Phase 2: Authentication and Supabase Configuration**
  - Configured `@supabase/supabase-js` client in `src/lib/supabase.ts`.
  - Built `AuthContext.tsx` with user state, session persistence, login, registration, and logout.
  - Implemented quiet editorial `AuthPage.tsx` with Sign In, Create Account, Forgot Password, and offline continuation.
  - Updated desktop Sidebar and Mobile navigation with user profile badge, sync status, and login triggers.
- [x] **Phase 3: Database Schema and RLS**
  - Authored complete PostgreSQL migration (`supabase/migrations/20261122_init.sql`).
  - Implemented tables: `profiles`, `journal_entries`, `collections`, `tags`, `entry_collections`, `entry_tags`, `reflection_templates`.
  - Configured Row Level Security (RLS) policies isolating user data strictly by `auth.uid() = user_id`.
  - Added automatic profile creation trigger on `auth.users`.
- [x] **Phase 4: Journal Editor and Entry Management**
  - Integrated TipTap 2 rich-text engine with Headings (H1/H2), Bold, Italic, Underline, Lists, Blockquotes, Links, and Undo/Redo.
  - Built sticky distraction-free toolbar with active state tracking.
  - Implemented entry types: Thought, Journal, and Reflection.
  - Created optional mood selector (Happy, Calm, Grateful, Curious, etc.).
  - Added reading time estimate and dynamic word counter.
- [x] **Phase 5: Autosave and Synchronisation**
  - Built two-tier persistence engine: IndexedDB (`idb`) + Supabase PostgreSQL.
  - Keystroke-level local draft caching with zero latency.
  - Debounced cloud autosave (600ms) with animated status badges (`Saving...`, `Saved to cloud`, `Offline — saved locally`).
  - Implemented offline sync queue that automatically pushes pending mutations when internet reconnects.
  - Entry management: Favourites, Archive, Soft/Hard Delete, and chronological retrieval.
- [x] **Phase 6: Collections and Tags**
  - Built `useCollections.ts` supporting full CRUD for user-defined collections and tags.
  - Interactive `CollectionsPage.tsx` with custom accent color selector, entry counts, and instant preview.
  - Multi-collection picker and inline `#tag` creator directly embedded in `EntryEditorPage.tsx`.
  - Non-destructive collection deletion (deleting a collection preserves all entries).
- [x] **Phase 7: Search and Timeline**
  - Full-text search across titles and journal prose.
  - Dual view modes in `JournalPage.tsx`: **Feed View** and **Timeline View** (chronologically grouped by Year and Month).
  - Subtle and nostalgic **"On This Day"** banner surfacing past thoughts written on the same calendar date in previous years.
  - Real-time collection and tag pill filters.
- [x] **Phase 8: Reflection Module**
  - Integrated template repository with pre-built models (Daily, Weekly, Decision, Experience).
  - Built custom reflection template creator (`useReflections.ts`) with custom prompt questions.
  - Guided session launcher that auto-structures prompts into TipTap and marks entries as `reflection`.
- [x] **Phase 9: Insights**
  - Activity patterns: dynamic word counts, average entry lengths, writing distribution bar charts, and monthly trend graphs.
  - Recurring themes: tag clouds and collection streams.
  - **Thought Evolution**: Side-by-side comparative inspection between past thoughts and recent perspectives.
  - **Unresolved Thoughts**: Filterable repository of open questions and queries.
  - Insight integrity: Explicit declaration that all stats derive directly from real user entries without fabrication.
- [x] **Phase 10: Export and Privacy**
  - Built multi-format export engines (`src/utils/export.ts`):
    - **Markdown (.md)** with YAML-style metadata headers and clean formatted body text.
    - **Plain Text (.txt)** chronological archive.
    - **JSON (.json)** full lossless backup of entries, collections, tags, and timestamps.
  - One-click client-side download generation directly in the browser with no external exposure.
  - Multi-tenant data privacy safeguards and explicit RLS declaration.
- [x] **Phase 11: Optional AI Integration**
  - Architected provider-independent interface (`src/lib/ai/aiProvider.ts`).
  - Implemented local on-device cognitive heuristic engine for zero-network private analysis.
  - Built interactive `AIWorkspaceModal.tsx` enforcing strict Part 11 consent workflows:
    - User selects specific entries via checkbox list.
    - Clear data disclosure notice explaining what is analyzed.
    - Generates reflection summaries, recurring themes, and deepening questions.
    - Explicit integrity disclaimer (suggestions, not psychological diagnoses).
- [x] **Phase 12: Testing, Optimisation and Deployment**
  - Strict TypeScript build and ESLint checks passing with 0 errors.
  - Production build optimized with Vite 8.
  - Responsive cross-platform layout tested on mobile and desktop viewports.
  - Prepared for instant Vercel / GitHub deployment.
